# Parity with the earlier port's bug reports

<https://github.com/michael-denyer/pstack-claude> is an earlier Claude Code port. Every bug or behavior report on its tracker is listed here with how this port handles it, so the same defects don't ship twice. Feature requests (#21, #46, #105, #261) and upstream syncs (#173, #260) are out of scope; this port tracks upstream through the `upstream` branch instead.

"Verified" means checked in a real `claude` session or against the real artifact; see [TESTING.md](TESTING.md).
